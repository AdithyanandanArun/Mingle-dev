Mingle 0.1.5 makes automatic compaction configurable per conversation and improves the floating browser and turn reviews.

- **Automatic compaction.** Set a percentage in the context usage popover. On supported conversations, reaching it pauses the active work for native compaction and resumes it when compaction succeeds.
- **Floating browser.** The page opens in a smaller panel at the bottom right and moves clear of the composer if needed. Drag the top edge to move it, resize from any corner, and click the top-right button to reveal the controls. The preview streams at higher resolution.
- **Questions and turn reviews.** Pending questions appear above the prompt. Turn reviews stay with their turns and show changed files and command outcomes by default, with a separate control for detailed evidence.
- **Typography.** Inline code now uses bundled JetBrains Mono.

Desktop downloads include Windows x64, Debian amd64, Arch x86-64, and a Linux x64 archive, each with a SHA-256 checksum.
