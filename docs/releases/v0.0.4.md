Mingle 0.0.4 simplifies sharing a conversation with teammates.

- **The current session is shared automatically when you invite someone.** Its existing agent becomes the orchestrator, without a separate session or orchestrator picker. Existing multi-agent conversations keep their group and configured lead.
- **Choose Supervised or Full access in Teammates.** The setup panel removes the leader toggle and fallback selectors. Advanced team management remains in Team structure. Raising permission still requires the relevant teammates to re-consent.
- **Existing team conversations stay shared.** Later invites keep the project's shared conversation, and removing the last remote agent keeps the shared session available. Older projects with enabled settings but no attached session can finish setup using the current conversation.
- **Setup failures are recoverable.** Email delivery and session-sharing status are reported separately, so sharing can be retried without sending the invitation again. Sharing preserves the local conversation and starts no provider run.

Downloads include the Windows installer, Debian package and Linux archive, each with a SHA-256 sidecar. Provider tools and accounts remain separately installed. The Windows installer is unsigned. Upgrading preserves existing Mingle user data.
