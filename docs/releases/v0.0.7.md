Mingle 0.0.7 makes cross-device teams hand work back and forth on their own: teammates' agents join the team session automatically, push finished work to their own GitHub branch, and the lead's orchestrator reviews and (with full access) accepts it without waiting for you.

- **Teammates' agents join automatically.** When a teammate shares agents with the team, every consented agent is added to the team session — no manual "Add agent" step. Agents you remove stay out until their owner shares them again.
- **Finished work is pushed to its own branch.** When a teammate's agent completes an assignment, Mingle commits its in-scope changes and pushes them to `mingle/<handle>/<task>` on the project's GitHub remote, using the teammate's own Git credentials. It never pushes to the default branch, never force-pushes and pushes no tags.
- **The orchestrator reviews and accepts on its own.** The lead's Mingle fetches the pushed branch for review and tells the orchestrator exactly what to inspect. With full access the orchestrator verifies the work, accepts it with a written verification summary and merges it locally; under Supervised, acceptance stays with you. Your own branch is never pushed without you.
- **One access level for the team.** The access you choose for the team session is the team's permission level. You can raise it while agents are working, and approvals already waiting are approved when the agent's consent covers the new level.
- **Joining a project no longer hangs.** A teammate returning after hours offline no longer has to work through hundreds of queued roster updates before a join completes, and owners stop queuing updates for teammates who are offline.
- **File handoffs between devices arrive reliably.** Messages from each device are handled in order, early chunks are retried instead of rejected, stuck transfers request a resend, and failures show their real reason.
- **Calmer team screens.** The teammate's session no longer flashes while its agent works, and status messages say plainly what is happening ("In progress", "Waiting for the team lead's approval", "1 task still open").

Because finished work is now pushed to GitHub automatically, teammates are asked to re-share their agents once after updating. All devices in a team should update to 0.0.7.

Downloads include the Windows installer, Debian package and Linux archive, each with a SHA-256 sidecar. Provider tools and accounts remain separately installed. The Windows installer is unsigned. Upgrading preserves existing Mingle user data.
