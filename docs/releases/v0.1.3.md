Mingle 0.1.3 adds in-app provider CLI updates, automatic session titles, and a restrained color style that can be switched back to monochrome.

- **Update CLIs in Mingle.** Detected stable Codex, Claude Code and OpenCode installations can use a private, versioned installation when a verified native updater is unavailable. Mingle validates the checked version before selecting it, keeps the original CLI in place, and offers **Use previous installation**. Updates and executable changes wait until the provider is idle. Native self-updaters remain available for supported installations. Managed installs require Node/npm on Linux or macOS; Windows retains supported native updates or manual instructions. Antigravity keeps its separate checksum-pinned runtime.
- **Automatic task titles.** New standalone sessions receive a concise local title from the first meaningful task, without an extra model call. Explicit names and later renames stay yours, including numeric names such as Session 1. Older generated placeholders are recovered in bounded batches. Commands, helper handoffs, code blocks and recognizable credentials do not become titles. Historic manually chosen numeric placeholders without rename evidence are ambiguous; rename one to record manual ownership.
- **Quiet color, easy reversal.** Dark and light themes gain subtle blue, teal and warm accents with lightly tinted surfaces. Choose **Settings → Appearance → Monochrome**, or use **Restore monochrome**, to restore the original palette. Theme and color style are saved independently.

Validation uses labelled Example data, scripted providers and disposable executable fixtures, with no paid inference or host CLI upgrades. The full local backend run passed 832 tests with one skipped; the final npm configuration correction passed 35 focused provider checks, including a real read-only npm configuration probe. All 217 web tests, TypeScript checks, production build, smoke tests and provider-update/appearance browser checks passed. Browser checks cover update and restore failures, persistence, keyboard use and 390px layouts. These checks do not establish live provider package download or login behavior.

Downloads include Windows x64 `.exe`, Debian amd64 `.deb`, Linux x64 `.tar.gz`, and Arch x86-64 `.pkg.tar.zst`, each with a SHA-256 sidecar. Install explicitly to update; existing workspace data is retained. Windows installers and Arch packages remain unsigned; macOS packages and automatic application updates are not included.
