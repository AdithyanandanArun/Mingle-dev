Mingle 0.0.1 for Linux x64 and Windows x64.

## Downloads

- **Debian/Ubuntu:** `sudo apt install ./mingle_0.0.1_amd64.deb`. If an earlier 0.1.0 test build is installed, add `--allow-downgrades`.
- **Windows:** run `mingle-0.0.1-win32-x64-setup.exe`. It installs per user. The installer is unsigned, so Windows may show an unknown-publisher prompt.
- **Other Linux (tarball):** extract `mingle-0.0.1-linux-x64.tar.gz` and run `./mingle-0.0.1-linux-x64/mingle`. For the Chromium sandbox, `chrome-sandbox` must be owned by root with mode 4755.

Each download has a `.sha256` file. The packages include Electron, Node, the web UI and the local server. Provider tools and accounts are installed separately.

## What's new

- Opening an email invitation shows a join prompt. You choose where to clone the repository, add one or more providers, then land in the team's shared chat.
- **Leader orchestration** for team projects:
  - The team lead's chosen agent orchestrates the work.
  - @mentions reach agents on any teammate's device.
  - Agents work in isolated worktrees on their owner's machine.
  - Committed results return through Git into separate `refs/mingle/team/…` references.
- Joining teammates choose which agents to share and accept a sandboxed-access disclaimer. They can pause, resume or leave at any time.
- A group-wide permission level, Supervised or Full access. Supervised approvals are mirrored to the lead.
- Clicking an agent in the presence bubble shows that agent's own conversation.
- **Team structure** view: an interactive tree. Drag an agent onto the leader slot to promote it or swap leaders. You can also bench agents as idle, order up to 4 fallback leaders, and see leader history.
- Automatic fallback when the leader runs out of quota or goes offline. With no usable fallback, work pauses until someone picks a new leader.
- On Linux, the launcher ignores `ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS` and `NODE_PATH` from the environment.

## Known limitations

- If the lead's device is offline, no new team work is scheduled.
- Plans, slash commands, skills and attachments can't yet be sent to agents on other devices.
- Not yet tested on two real devices or on Windows hardware. The Windows build is checked only by CI.
