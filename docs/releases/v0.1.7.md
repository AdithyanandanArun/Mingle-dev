Mingle 0.1.7 fixes two causes of excessive memory use in the built-in browser and improves everyday workspace controls.

- **Shared browser stability.** The live view waits for viewers before capturing more frames. Mingle also clears object-heavy debugger logs during bursts so busy pages don't leave those objects pinned in memory.
- **Desktop updates.** A downloaded update can still be restarted from Settings after its notice is dismissed. When installation fails, Mingle provides a verified installer path.
- **Workspace refinements.** Choice menus stay in view, model search matches aliases, and the conversation handles wide images and blank code blocks more reliably.
