Mingle 0.0.10 addresses feedback from real user testing across agent sessions, team controls, provider setup and Linux sign-in storage.

- **Automatic subagent activity.** Model-spawned Claude, Codex and OpenCode children appear in the Subagents rail with available provider/model details, messages, tool activity and results. Mingle-managed delegation returns results to its parent automatically. No manual Subagent button or special command is required. Child sessions stay nested under their parent.
- **Send while an agent works.** Codex supports native turn steering. Other messages queue durably with their attachments and skills. Edit, remove or send a queued message immediately; Send now interrupts safely and prioritizes that message. Other providers still receive queued messages between turns.
- **Easier team management.** Add agents while the coordinator works. A preferred coordinator can reclaim its role after quota recovery, with an explicit restore action when needed.
- **Start in ordinary folders.** Chat in a folder without Git; optionally initialize Git and create a GitHub repository. Initial staging excludes private files and oversized files, including when ignore rules negate secret patterns. GitHub creation/push remains an explicit action.
- **Provider and keyring setup.** Desktop launch imports the login shell PATH and searches common provider installation locations. OpenCode failures give clearer diagnostics; Antigravity installation reports readiness. Linux keyring selection prefers running services, remembers a verified choice, protects older wrapped keys, and offers a user selection in Account settings.
- **UI cleanup and recovery.** Clearer session labels, compact header/composer controls, responsive settings tabs, and improved child-agent presentation. Restart recovery respects the automatic-resume preference.

Validation uses disposable Example workspaces, fake providers and local Git repositories; it submits no paid inference. Browser collaboration checks use explicitly labeled cloud/auth/email fixtures. Live provider accounts, physical-device collaboration and every Linux keyring configuration are not established by these automated checks.

Downloads include Windows x64 `.exe`, Debian amd64 `.deb`, Linux x64 archive and Arch x86-64 package with SHA-256 sidecars. The Windows installer and Arch package are unsigned. Updates preserve user data and require an explicit installation; provider runtimes and sign-ins remain separately managed.
