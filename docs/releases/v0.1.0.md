Mingle 0.1.0 brings autonomous single-agent work, shared project memory and a faster chat experience to the desktop workspace.

- **Autonomous goals.** Choose Autonomous in a standalone conversation to work toward a goal across provider turns. Follow the checklist, helper activity and turn budget, and use Pause, Stop or Resume whenever needed. It keeps the selected conversation and native permissions. Failed or uncertain runs, unanswered questions and declined permissions remain visible boundaries; restarting Mingle pauses the goal until you resume it. An agent's completion report leaves the task in Review.
- **Faster long conversations.** Streamed text redraws the live message instead of the entire transcript. Background sessions no longer redraw the active conversation's messages. State refreshes preserve unchanged records, coalesce streaming bursts and avoid repeatedly serializing the whole workspace. Automatic follow-through prompts stay compact and inspectable.
- **Autonomous project memory.** Agents can record and recall project decisions, conventions, gotchas and verification references. Inspect, correct, pin or retire entries and review their history. Team-bound projects share memory over the existing encrypted transport; causal history protects human pins and retirements during offline edits. Referenced files can mark knowledge stale. Evidence describes checked references, not a guarantee that a statement is true.
- **Provider discovery and updates.** Model and effort choices follow the provider's reported catalog, with explicit handling for unavailable metadata and custom model IDs. Startup can report available provider updates; updating remains an explicit Settings action with installation checks and active-run protection.
- **Smoother Full access teamwork.** Authorized remote runs use their provider's native Full access policy. Review work stays open until verified integration and configured publication succeed; failed publication can be retried. Coordinator handoffs preserve acceptance authority and follow-up delivery.
- **Desktop and browser refinements.** Startup restores the last project instead of opening a starter workspace. Flat neutral surfaces replace blue accents and gradients. Workspace headers stay within their bounds, embedded browser tabs stay in their pane, and task/subagent surfaces retain keyboard and narrow-layout support.

Validation includes 740 passing server tests and one skipped test in the full suite, 96 web tests, 43 browser checks, transcript/store performance fixtures, and focused regressions after review. Native packages are built and checked separately on Linux and Windows. Automated workflow tests use fake providers and disposable repositories; they do not establish live paid-provider or physical cross-device reliability. See the [autonomy acceptance report](https://github.com/AdithyanandanArun/Mingle-dev/blob/v0.1.0/docs/single-agent-autonomy-acceptance.md) for the exact scope and limits.

Downloads include Windows x64 `.exe`, Debian amd64 `.deb`, Linux x64 `.tar.gz`, and Arch x86-64 `.pkg.tar.zst`, each with a SHA-256 sidecar. Install explicitly to update; existing workspace data is retained. Provider tools and sign-ins are managed separately. Windows installers and Arch packages remain unsigned; macOS packages and automatic application updates are not included.
