Mingle 0.0.9 overhauls the shared browser with native desktop pages, automatic human takeover, and optional per-site sign-in import.

- **Built-in sandboxed browser.** Desktop sessions can use Electron's Chromium directly inside Mingle, without a separate Playwright Chromium download. Fresh settings prefer this mode; existing saved browser choices are preserved. Settings → Browser lets you change the default. Web-only runtimes fall back to managed Chromium when no desktop host is available.
- **Step in naturally.** Click, type or scroll to take over a shared page. The agent can resume about 2.5 seconds after activity stops. Keep control pins your lease until you hand it back, and a held native drag retains control. Agent-generated input is distinguished from native input without the previous suppression window.
- **Optional sign-in import.** Use my sign-ins lets you explicitly select a local browser profile and sites whose cookies should be copied into the session. Cookies include those sites' subdomains and grant agents access to the imported sign-ins. No passwords or whole profiles are imported. Firefox and supported Linux/macOS Chromium formats are available; Windows Chromium app-bound encryption and KWallet are unsupported. Google may still reject embedded or automated login; Mingle does not bypass those checks.
- **Clearer managed-browser setup.** Linux user-namespace/AppArmor detection reports specific setup guidance and, where supported, offers an explicitly authorized AppArmor profile for the selected Chromium. Built-in browsing avoids the separate Chromium installation. Sandbox protections remain enabled.
- **Reliable native controls and windows.** Fixed address-bar navigation, Keep control/Hand back, full view, popout ownership, overlay streaming fallback, and CDP session lifetime/routing. Native toolbar actions require authenticated proof that the exact session tab is presented. Provider processes do not inherit the desktop's unrestricted relay credentials.

Local verification includes 13 full-desktop acceptance checks, 85 focused server/provider tests, 41 web tests, 19 desktop protocol/preload checks, a production build, and extended sandbox-enabled Electron smoke checks. These use disposable Example workspaces and synthetic cookies, without inference. Native acceptance ran on Arch Linux; real Ubuntu AppArmor installation, Windows/macOS browser behavior, and live Google sign-in remain unverified.

Downloads include a Windows x64 installer, Debian amd64 package, Linux x64 archive, and Arch x86-64 package, each with a SHA-256 sidecar. The Windows installer and Arch package are unsigned. Install the downloaded update explicitly; Mingle has no automatic updater. Existing user data is preserved. Provider executables and their logins remain separately installed.
