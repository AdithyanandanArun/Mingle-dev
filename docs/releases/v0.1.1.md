Mingle 0.1.1 adds account usage in Settings and refines the single-agent workflow from composing a goal to reviewing its results.

- **Settings → Usage.** View Codex and Claude Code account limits, reported five-hour and weekly windows, remaining percentages, and reset times without opening a coding session. Refresh each provider independently. Redeem eligible Codex earned resets with confirmation and the same request ID on uncertain retries. Claude reset management opens its official Usage page because Claude Code exposes no native redemption API. Unavailable data stays explicitly unknown; the page does not poll providers in the background.
- **A simpler composer and progress strip.** Choose Chat, Plan, or Autonomous in one selector. Model and permissions stay visible; effort, service tier, and goal budgets live in advanced settings. One expandable progress surface brings together the current task, checklist, helper activity, and goal controls.
- **Better long conversations.** Load older messages on demand, preserve the reading position, and defer offscreen layout and paint. Session snapshots replace many whole-workspace refreshes while startup and reconnect retain full recovery snapshots. Full expanded tool output survives shortened snapshots and stale detail replies.
- **Factual completion and recovery.** Review recorded changes, executed commands, failures, agent reports, and outstanding checklist work separately. Tasks remain in Review. Recovery guidance follows the classified failure; a generated autonomous turn retries at most once only with server evidence that it was not dispatched and has no uncertain side effects. An early timer wakeup no longer falsely exhausts a goal's time budget.
- **Inspectable context and easier navigation.** Inspect attachments, context references, memory previews, and saved injection details. Exclude project memory for one turn with server enforcement. Search loaded messages, jump to activity and changes, bookmark conversation locations, and edit queued messages with stale-edit protection. Drafts and reader positions persist in bounded browser-local storage; keyboard controls, narrow layouts, and reduced-motion preferences are preserved.

Local validation passed 795 server tests (one skipped), 206 web tests, contracts/server/web TypeScript checks, the production web build, and the Settings Usage browser acceptance at 390px and 900px. Earlier refinement checks also cover history, navigation, context, tool output, completion review, scoped refresh, and autonomous workflow controls. Automated checks use labeled Example fixtures and scripted providers; real account reset redemption and paid provider workflows were not exercised. Search covers loaded messages, offscreen rows remain mounted, and browser-local drafts/bookmarks do not sync across devices. See the [refinement roadmap](https://github.com/AdithyanandanArun/Mingle-dev/blob/v0.1.1/docs/single-agent-refinements.md) and [Usage implementation notes](https://github.com/AdithyanandanArun/Mingle-dev/blob/v0.1.1/docs/provider-account-usage.md) for details and limits.

Downloads include Windows x64 `.exe`, Debian amd64 `.deb`, Linux x64 `.tar.gz`, and Arch x86-64 `.pkg.tar.zst`, each with a SHA-256 sidecar. Native packages are built and checked on GitHub's Linux and Windows runners before publication. Install explicitly to update; existing workspace data is retained. Provider tools and sign-ins are managed separately. Windows installers and Arch packages remain unsigned; macOS packages and automatic application updates are not included.
