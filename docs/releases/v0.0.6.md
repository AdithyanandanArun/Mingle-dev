Mingle 0.0.6 makes teammates' agents, shared sessions and remote orchestration work reliably across devices, and makes team updates near-instant. It also includes the 0.0.5 interface refresh, which was not published separately.

- **Team updates arrive in about a tenth of a second.** Settings, consent and roster changes reach other devices in roughly 120 ms instead of several seconds. Messages travel over persistent, end-to-end encrypted realtime channels, with the cloud mailbox kept as the durable fallback.
- **Team views open instantly.** Team structure, agents and members are served from a local copy that refreshes in the background and updates as soon as a team change arrives.
- **Adding teammates' agents works.** Agents are no longer limited to supervised mode, published agents keep stable identities across devices, and "local session is unavailable" errors are fixed.
- **New members see the shared session right away**, and other devices see them join without reloading. Teammates are shown by their handle.
- **Full access reaches every teammate.** Raising the permission level only asks teammates below the new level to re-consent.
- **Long remote tasks no longer time out.** Remote agents report progress while they work, and replies no longer get stuck in "sending".
- **0.0.5 interface refresh:** a first-launch welcome tour with optional sign-in, a provider-aware model picker, higher text contrast, and polished workspace and team screens.

Downloads include the Windows installer, Debian package and Linux archive, each with a SHA-256 sidecar. Provider tools and accounts remain separately installed. The Windows installer is unsigned. Upgrading preserves existing Mingle user data. All devices in a team should update to 0.0.6.
