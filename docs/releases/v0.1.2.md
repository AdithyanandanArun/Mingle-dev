Mingle 0.1.2 moves helper subagents into a floating bubble, keeps finished helper handoffs out of the conversation, and gives the composer's activity and questions one calmer surface.

- **Floating helper bubble.** Helpers from Claude, Codex, OpenCode and Mingle-managed delegation appear in a bubble at the top right of the session instead of inside the composer. Running helpers come first, and the header counts only those. Finished results and cancelled or failed helpers sit in separate history sections that start collapsed. Interrupted native runs appear with cancelled and failed helpers and keep their Interrupted label. The bubble steps aside when the context pane opens.
- **Live-only lists.** The bubble and the left sidebar show only running helpers. The sidebar nests a running helper under its parent session, including while its child session is idle or waiting for input. When a helper settles, it leaves those live views and stays reachable from the bubble's history.
- **One composer outline.** The progress strip, checklist, helper waits and pending questions share the composer's outer border and focus ring. Settled activity animates closed and hides itself, and a finished helper no longer keeps the strip open. Paused autonomous goals keep their Resume and Stop controls.
- **Inline question answers.** A pending provider question opens an answer form above the composer. Submit, cancel and error handling work as before. Answered and cancelled questions stay in the transcript. Reduced-motion preferences turn these animations off.
- **Private helper handoffs.** When a helper finishes, its result returns to the parent session as internal, server-marked provenance. The parent still continues or steers from it, and the child session and helper record keep the full result for inspection. Chat, search and the editable queue hide the raw handoff text, and the handoff continues the existing request instead of creating a task. Messages you type that look similar stay visible. Restart notices for interrupted helpers follow the same rule. Older history is not reclassified, so earlier result text stays where it was.

Checks use labelled Example fixtures and scripted providers and submit no paid model inference. They cover 30 browser checks (17 composer activity, 13 automatic subagent), 22 focused web tests, and the TypeScript, production build and smoke checks run during implementation.

Downloads include Windows x64 `.exe`, Debian amd64 `.deb`, Linux x64 `.tar.gz`, and Arch x86-64 `.pkg.tar.zst`, each with a SHA-256 sidecar. Install explicitly to update; existing workspace data is retained. Provider tools and sign-ins are managed separately. Windows installers and Arch packages remain unsigned; macOS packages and automatic application updates are not included.
