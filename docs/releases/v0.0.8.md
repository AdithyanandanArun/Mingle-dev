Mingle 0.0.8 adds clearer task progress, provider subagent conversations, and more resilient local and cross-device team work.

- **Expandable task progress.** The compact task strip above the composer shows the current task and recorded progress. Expand it to inspect the checklist, then collapse it to reclaim space.
- **Progress boards and subagent conversations.** Follow task dependencies, agent health, handoffs, and acceptance state from the session. Provider-reported subagent activity appears in the side rail; devices identify their own agents correctly.
- **Continue interrupted work.** Automatic continuation after restart is enabled by default and can start provider work. Disable it in Settings → General if you prefer manual resumption. Continuations are bounded, respect provider availability, and do not carry old approvals forward; uncertain actions and recovery holds still require review.
- **More resilient Full-access teams.** Dependency-aware assignment routing, bounded retries, saved cooldowns, and recovery state help eligible work continue. Supervised checkpoints and owner consent remain enforced.
- **Accepted team work reaches the integration target.** Under Full access, verified accepted work is merged into the team's configured integration branch, defaulting to origin's default branch, and published with the host's Git credentials. Mingle fetches remote advances before publishing, stops on merge conflicts, and never force-pushes. Supervised acceptance and pushes remain human-controlled. The integration target cannot change during active deliveries.
- **Provider and Git recovery improvements.** Retry failed messages with their attachments, switch providers through an explicit conversation handoff, track provider background subagents accurately, and use the signed-in Mingle identity for team commits when local Git identity is missing. OpenCode and Antigravity can use the local stdio fallback for supported progress/team tools.

Update every device participating in a team to 0.0.8. Provider executables, provider logins, and Git credentials remain separately installed on each device. Upgrading preserves existing Mingle user data.

Downloads include the Windows x64 installer, Debian amd64 package, Linux x64 archive, and Arch x86-64 package, each with a SHA-256 sidecar. The Windows installer and Arch package are unsigned. There is no automatic updater or AUR package; install the downloaded update explicitly.

This release is checked with local automated tests and native packaging smoke checks. Those checks do not establish cross-continent latency or replace a live two-device/provider acceptance run.
