Mingle 0.1.4 adds a page-first floating browser and brings context usage and native compaction into the composer.

- **Floating browser.** When an agent opens a page in the selected conversation, it appears at the bottom right. A compact control bubble opens full view or a separate desktop window, docks the browser, minimizes it, or disconnects it. Dock the browser to use the address bar, tabs, and driving controls.
- **Context usage and compaction.** The ring next to Send shows the latest available context reading, including the provider's token count and capacity when reported. It turns yellow above 70% and red above 90%. Open it to compact a supported conversation while keeping your draft and attachments.
- **Simpler conversation controls.** Explicit planning and keep-working requests can start a plan or a bounded goal directly from the composer. Agents can ask clarification questions during ordinary turns. The model picker takes less room and supports keyboard search.
- **Workspace polish.** Activity has search and filter reset, shared dropdowns have better keyboard navigation, and Linux users can choose whether to show the system title bar in **Settings → Appearance**. Restart Mingle to apply the title bar setting. Dark and light themes use neutral colors.

Downloads include Windows x64, Debian amd64, Arch x86-64, and a Linux x64 archive. Each file has a SHA-256 checksum. Install the new package explicitly to update. Existing workspace data stays on the device.
